## graph/euler_tour

オイラーツアー + RMQ による木ユーティリティ。

- `add_edge(u, v, weight=1)` で無重み木・重み付き木を統一
- LCA
- 祖先判定
- 部分木サイズ
- 2頂点間の辺数
- 2頂点間の重み付き距離
- 根からの重み付き距離
- 静的な頂点コストの部分木和・パス和
- 静的な辺コストの部分木和
- 最遠点取得

旧 `graph/tree.py` の機能を統合済み。
